CONNECTED PAEDIATRICS POSTURE & ALIGNMENT — v13

Deployment: upload the seven files in this folder to the root of the existing GitHub Pages repository. Replace the existing files; upload the individual files, not the ZIP. Reload the published website, or close and reopen the installed web app after the service worker refreshes.

NEW
- Save assessment to self-contained JSON (photos, landmarks, measurements, photo quality, date, observations).
- Load a previous JSON assessment as baseline, without overwriting your current work.
- Reload a saved JSON to continue editing an assessment (replaces current work after confirmation).
- Front, side and back before/after previews and signed angular change tables.
- Regional alignment overlays and corrected rotated-marker-based plumb line.
- Six quality checks including camera/stance/marker repeatability.
- Separate print-ready clinician and parent reports, including comparisons when a baseline is loaded.

IMPORTANT
Photos and JSON files may contain identifiable patient information. Store and share only through compliant patient-record processes. No cloud account or server-side patient database is included. Auto-pose detection still requires the external MediaPipe library, loaded on request.
The browser print dialog provides Save as PDF. Assessments are clinical observation aids, not diagnostics.
